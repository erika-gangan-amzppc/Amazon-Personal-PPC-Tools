PPC Tools

Personal toolkit — everything here runs client-side, no uploads, no server.

  • Multi-Report PPC Audit

    Bulk sheet + search term report + business report → account overview, ad type / targeting / match type breakdowns, harvest & wasted-spend findings, untargeted ASIN opportunities, and dynamic recommendations.

    bulk sheetsearch term reportbusiness report

  • Negation Tool

    Bulk sheet + search term report → the back half of the harvest waterfall: terms already harvested elsewhere that still need negating in their discovery campaign, plus plain wasted-spend negatives. Checks existing negatives first so nothing gets recommended twice.

    bulk sheetsearch term report

  • Harvest Tool

    Bulk sheet + search term report → two-way harvest: promote proven terms to their own Exact keyword, or isolate proven Broad/Phrase terms into a dedicated keyword at the same match type. Exports a ready-to-paste new-keyword CSV.

    bulk sheetsearch term report
